## Suggested Workflow

1. Read the weekly `README.md` before opening notebooks or slides.
2. Keep each notebook in its original weekly directory so bundled data files resolve without path edits.
3. Run notebooks from the repository root or from the matching weekly folder.
4. Record questions from the paper readings and notebooks before joining discussion or office hours.

## Local Setup Reminder

The course materials use common scientific Python tools. A minimal local environment should include JupyterLab plus NumPy, SciPy, pandas, Matplotlib, and Astropy:

```bash
python -m pip install jupyterlab numpy scipy pandas matplotlib astropy
```

Some activities also use external services such as GitHub, Google Drive, Overleaf, Kaggle, NASA Exoplanet Archive, MAST, and Gaia. Check the weekly README for the accounts or links needed before starting that week's work.
